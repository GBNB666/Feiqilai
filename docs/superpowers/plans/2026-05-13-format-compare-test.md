# 2026-05-13 论文格式对照测试 & Bug 修复

## 背景

之前开发过程中出现了多个格式 Bug（正文粗体传播、字体变蓝、表格图片占位丢失等），用户是大二学生，对论文排版深层规则理解有限，无法精准描述 Bug。改用"对照实验"方式发现和定位问题。

## 测试方法

1. 用户找一篇**格式完全正确**的论文 → 称为 **"标准文件"**
2. 用户手动把标准文件的格式打乱 → 称为 **"打乱文件"**
3. 用户把两个文件都发给我
4. 我把"打乱文件"上传到排版系统，让 AI 分析并修正格式
5. 导出修正后的结果 → **"修正文件"**
6. 逐项对比"修正文件"和"标准文件"的差异
7. 每个差异就是一个 Bug 或不足 → 记录 → 修复

## 对比维度

对比时重点关注以下方面：

### 文字格式
- [ ] 字体名称、大小是否一致
- [ ] 粗体/斜体/下划线是否正确恢复，有无传播扩散
- [ ] 字体颜色是否正确（检查蓝色bug）
- [ ] 上标/下标是否保留

### 段落格式
- [ ] 对齐方式（两端对齐、居中、左对齐）
- [ ] 行间距（单倍/1.5倍/双倍/固定值）
- [ ] 段前段后间距
- [ ] 首行缩进

### 标题层级
- [ ] 各级标题字体大小是否正确
- [ ] 标题编号是否保留
- [ ] 标题加粗/居中是否正确

### 表格
- [ ] 表格是否存在（有无丢失）
- [ ] 单元格内容是否完整
- [ ] 表格边框样式
- [ ] 合并单元格是否保留

### 图片
- [ ] 图片是否存在（有无丢失）
- [ ] 图片位置是否大致正确
- [ ] 图片大小/比例
- [ ] 题注（图1/表1等编号）是否保留

### 特殊元素
- [ ] 页眉页脚
- [ ] 页码
- [ ] 目录（如有）
- [ ] 参考文献格式
- [ ] 摘要/关键词格式

## 输出

对比完成后产出一份 Bug 清单：

| # | 严重程度 | 问题描述 | 对比证据（标准文件 vs 修正文件） | 猜测原因 |
|---|---------|---------|-------------------------------|---------|
| 1 | 严重/中等/轻微 | ... | ... | ... |

## 修复优先级

1. 先修严重 Bug（导致内容丢失或格式彻底错乱的）
2. 再修中等 Bug（格式明显不对但不丢内容）
3. 最后修轻微 Bug（格式基本对但细节偏差）

## 交付物

1. Bug 清单
2. 各 Bug 修复代码
3. 修复后用同一对文件重新测试验证

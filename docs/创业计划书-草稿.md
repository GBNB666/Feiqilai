# 《智排AI》创业计划书

---

## 一、概述

### 1.1 项目简介

"智排AI"是一个面向在校师生的论文与文档AI格式排版平台。用户上传docx文档后，通过自主划分段落层级配合AI精准识别，一键自动完成符合学术规范的格式排版。产品先以微信小程序形态上线，后续扩展至Web端，最终覆盖论文排版、结构分析、AI降重三大核心场景。

### 1.2 市场概貌

当前全国高校在校生超过4000万人，加上教师群体，每年产生的课程论文、毕业论文、竞赛申报书、教师报告等需要规范格式排版的文档数以亿计。以本校为例，仅师生群体就有至少5000人的直接需求——从教师的报告格式、文章格式，到学生的课堂论文、创新创业比赛申报书，格式排版是横跨所有学科的刚性需求。

### 1.3 经营策略

**先上小程序，再扩Web端。** 微信小程序天然适合校园场景——无需下载、群分享即用、支付闭环完整。当前已完成Web端和小程序端双模式框架搭建，首期聚焦小程序上线，通过校园社群和口碑传播获取种子用户。待小闭环（上传→分级→排版→下载）跑通后，快速迭代加入AI结构分析和AI降重功能。

### 1.4 财务预测摘要

- 初始投入：域名及服务器费用9000-15000元，小程序认证及开发费用500-3300元
- 盈利模式：基础排版免费，高级功能（批量处理、AI降重、多模板）按次或包月收费
- 预计6-8个月达到盈亏平衡，首年服务用户3000+人次

### 1.5 个人优势

项目发起人博博，护理学专业在校大学生。非计算机专业背景，凭借对论文格式痛点的亲身体验，自学Python、FastAPI、React、TypeScript等编程技术，利用DeepSeek等AI工具辅助开发，从零搭建起完整的论文排版系统。这一跨学科创新能力，正是当下"新医科+新技术"融合发展的典型实践。

## 二、产品/服务

### 2.1 核心功能

智排AI提供四条核心能力链：

**① 自主分级 + AI精准排版**
用户上传docx后，系统引导用户先对段落层级进行划分（一级标题/二级标题/正文等），再由AI精准执行格式排版。这与市面竞品形成本质差异化——竞品均为"AI全自动识别→排版"，识别不准且用户无法干预；智排AI让用户掌握控制权，AI作为高效执行工具。

**② 浏览器本地处理，隐私零风险**
所有文档处理在用户浏览器本地完成，不上传至云端服务器。论文作为学生和教师的核心学术资产，不存在内容泄露、被第三方存储或用于模型训练的风险。

**③ 多级标题自主定义格式**
用户可自定义各层级标题和正文的字体、字号、行距、缩进等参数，满足不同高校、不同期刊的个性化格式规范。并非"一键排版后锁死"，而是始终保留用户微调空间。

**④ 格式标准精准覆盖**
内置护理学等医学类论文四级标题体系（一、(一)、1.、(1)），同步支持不同学科的格式规范。后续将通过模板市场覆盖更多高校和期刊标准。

### 2.2 技术架构

| 层级 | 技术选型 |
|------|----------|
| 前端 | React 19 + TypeScript + Vite + Tailwind CSS |
| 后端 | Python FastAPI |
| AI引擎 | DeepSeek API（结构分析、降重建议） |
| 文档处理 | python-docx（本地排版引擎） |
| 部署 | 微信小程序 + Web端（后续扩展） |

### 2.3 产业化路径

1. **第一阶段**（当前）：小程序上线，覆盖本校师生，验证产品-市场匹配
2. **第二阶段**（3-6个月）：加入AI论文结构分析功能，识别论文逻辑框架并给出优化建议
3. **第三阶段**（6-12个月）：加入AI降重功能，覆盖论文写作全流程（排版→结构→降重）
4. **第四阶段**（12个月+）：扩展至更多高校，建立格式模板市场，实现商业化运营

## 三、市场

### 3.1 市场容量

| 维度 | 数据 |
|------|------|
| 全国高校在校生 | 4000万+ |
| 每年毕业生 | 1000万+（均需提交毕业论文） |
| 年均课程论文量/人 | 3-8篇 |
| 教师年均报告/论文需求 | 2-5篇 |

### 3.2 目标市场细分

**一级市场（核心用户）：** 医学/护理学类专业大学生——毕业论文格式要求严格，发起人具有该领域深刻理解

**二级市场（扩展用户）：** 全学科在校大学生及研究生——课程论文、开题报告、竞赛申报书均有格式需求

**三级市场（延伸用户）：** 高校教师及科研人员——课题申报书、学术报告、期刊投稿格式排版

### 3.3 市场切入点

以本校为起点，利用发起人护理学专业背景和校园人际关系，通过班级群、专业群精准触达目标用户。初期以"免费+好用"建立口碑，一个班级只要有3-5人使用并推荐，即可快速覆盖整个专业。

## 四、竞争

### 4.1 竞争格局

当前论文排版工具可分为四类，各有明显痛点：

**一、传统办公软件（Word/WPS）——最大"竞品"**

| 痛点 | 说明 |
|------|------|
| 操作门槛高 | 需掌握样式、多级列表、分节符等专业概念，新手需数小时学习 |
| 格式稳定性差 | 插入图表/分节符易引发全文格式塌方、页码错乱 |
| 效率极低 | 手动排版一篇论文需4-6小时 |
| 参考文献困难 | 手动调整200+条文献格式，错误率超30% |
| 兼容性问题 | Word/WPS互转时表格、公式易错位 |

**二、专业排版工具（LaTeX/Overleaf/Typst）**

| 痛点 | 说明 |
|------|------|
| 学习成本极高 | LaTeX需数周掌握语法与宏包 |
| 非技术用户不可用 | 命令式编写、环境搭建，普通师生难以使用 |
| 协作不便 | 导师多习惯Word，格式互转易丢失内容 |

**三、在线AI排版工具（Paperxie/笔捷AI/知网助手等）**

| 痛点 | 说明 |
|------|------|
| 分级识别不准 | AI自动分级常误判标题层级，需大量手动修正 |
| 模板覆盖不全 | 地方高校、小众专业模板严重缺失 |
| 付费套路多 | 免费版功能受限、水印、广告弹窗，会员价格高 |
| 下载受限 | 未付费仅预览/无法下载，付费后仍有格式瑕疵 |
| 隐私风险 | 论文上传云端，存在内容泄露与存储隐患 |
| 无法自主干预 | AI排版后用户难以精准微调 |

**四、通用痛点（全品类共性）**

- 无分级前置机制：均未要求用户先自主划分段落层级，AI识别准确率低
- 预览与下载割裂：未付费仅看前几页
- 支付信任度低：多为第三方支付，无微信商家官方支付
- 本地化不足：多数工具侧重通用/英文场景，中文高校规范适配差

### 4.2 智排AI差异化优势

| 竞品痛点 | 智排AI对策 |
|----------|-----------|
| AI分级不准 | **自主分级+AI执行**——用户先划分层级，AI精准排版 |
| 隐私风险 | **浏览器本地处理**——文档不上传服务器 |
| 无法微调 | **自定义格式**——用户可自主修改各层级字体、字号、行距 |
| 付费套路 | **基础免费+增值收费**——排版核心功能免费，高级功能付费 |
| 下载受限 | **无预览限制**——排版完成即可下载完整文件 |
| 模板不全 | **开放模板体系**——后续支持用户自定义和分享格式模板 |

## 五、营销

### 5.1 推广策略

**第一阶段：校园口碑传播（0-3个月）**
- 在本校护理学院、医学院班级群首发，邀请5-10名同学校友内测
- 制作1分钟操作演示短视频，在班级群、朋友圈传播
- 在毕业论文季（3-6月）集中推广，抓住刚需时间窗口
- 嵌入创新创业比赛场景：参赛团队可用智排AI快速排版申报书

**第二阶段：跨校扩展（3-12个月）**
- 通过已使用学生向其他高校同学推荐，利用微信小程序"即搜即用"特性
- 在知乎、小红书发布"论文排版攻略"类内容，软性植入产品
- 与高校教务处、学工部合作，作为官方推荐工具

**第三阶段：付费转化（6个月+）**
- 高级功能（AI降重、批量处理、多模板）按次收费或包月订阅
- 教师端推出"班级管理"功能，一个老师可管理全班学生论文格式

### 5.2 盈利模式

| 层级 | 功能 | 定价策略 |
|------|------|----------|
| 免费版 | 基础排版（单篇）、标准模板 | 永久免费 |
| 单次付费 | AI降重、高级模板 | 3-5元/次 |
| 包月会员 | 无限排版+降重+全部模板 | 19.9元/月 |
| 年费会员 | 全部功能 | 99元/年 |

### 5.3 收入预测

- 首年（种子用户+口碑期）：预计服务3000+人次，付费转化率5-8%，收入约5000-15000元
- 第二年（跨校扩展期）：用户数增长至10000+，付费转化率10-15%，收入约50000-100000元
- 第三年（稳定运营期）：用户数30000+，多元化收入（会员+企业/学校合作），收入约150000-300000元

**博博** —— 项目创始人 & 全栈开发者

- 护理学专业在校本科生
- 非计算机专业背景，自学编程
- 掌握技术栈：Python（FastAPI）、JavaScript/TypeScript（React）、微信小程序开发、AI工具链应用
- 核心能力：跨学科思维、快速学习能力、从用户视角定义产品的同理心
- 项目缘起：自身被论文格式排版困扰→发现市场空白→利用AI工具自学编程→从零搭建产品

### 7.2 项目起源

本项目由博博个人提出，在护理学专业学习过程中深切体会到论文格式排版的繁琐与低效——一篇课程论文花费在格式调整上的时间往往超过写作本身。在与专业老师交流后，老师建议将这一痛点转化为创新项目，以护理学为起点服务更广泛的在校师生群体。

### 7.3 组织规划

目前项目由博博独立开发和运营。待小程序上线并验证商业模式后，计划：
- 引入1-2名技术合伙人（前端/后端）
- 邀请护理学专业教师担任学术顾问
- 注册成立公司，规范股权结构和运营管理

### 7.4 未来规划

小闭环跑通后，后续迭代速度将大幅加快——核心原因是排版引擎的模块化架构使得功能扩展只需增加新的"处理模块"（如AI结构分析模块、AI降重模块），而无需重构已有代码。技术架构的高扩展性是快速迭代的基础保障。
